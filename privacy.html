개인정보처리방침

시행일: 2026년 11월 1일

이 방침은 "지구프렌즈 업로드 도구"(이하 "도구")가 Google 계정 데이터를 어떻게 다루는지 설명합니다. 도구는 지구프렌즈 유튜브 채널 운영자 본인이 자기 채널을 관리하려고 만든 개인용 프로그램이며, 다른 사람의 정보를 수집하지 않습니다.

1. 이용하는 Google 데이터와 목적

  • YouTube 채널에 영상을 업로드하고, 제목, 설명, 태그, 썸네일, 공개 일정을 수정하는 데 필요한 권한(YouTube Data API)만 요청합니다.
  • 업로드한 영상의 처리 상태와 채널 성과 수치를 읽어 운영자에게 보여줍니다.

2. 수집, 저장, 보관

  • 도구는 채널 운영자의 개인 컴퓨터에서만 실행됩니다. 별도 서버로 데이터를 보내거나 저장하지 않습니다.
  • 로그인 후 발급되는 인증 토큰은 운영자의 컴퓨터에 파일로만 보관되며, 운영자가 파일을 삭제하면 사라집니다.
  • 이름, 이메일, 연락처 같은 개인정보를 따로 수집하거나 데이터베이스에 쌓지 않습니다.

3. 제3자 제공과 공유

Google 사용자 데이터를 제3자에게 판매, 제공, 공유하지 않습니다. 광고 목적이나 AI 모델 학습에 사용하지 않습니다.

4. Google API 서비스 사용자 데이터 정책

이 도구가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 일은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 권한 철회와 삭제

언제든 Google 계정의 타사 앱 액세스 관리에서 이 도구의 접근 권한을 해제할 수 있습니다. 권한을 해제하면 도구는 더 이상 채널에 접근할 수 없습니다.
